# relational-algebra-query-tree
Set up the development environment:

- Install Git

- Install Anaconda distribution (bookmarks)


```bash
conda env list                                  # get a list of all my environments, active environment is shown with *. It will display the base environment.

conda create --file environment.yml             # in the repo create new Python environment

conda env list                                  # view the new environment created

#Activate the environment and check if we are in the right environment:
conda activate testenv
conda env list

conda list                                      # check if a package is installed
```
